# El Gran Telón

Aplicación móvil educativa para niños de 8 a 12 años. El niño declama
poemas en voz alta frente a un teatro virtual; Bemo, la luciérnaga que
es el reflector del escenario, reacciona en vivo a su voz real —volumen,
entonación, ritmo y pausas— mientras declama.

## Compilar

```bash
./gradlew assembleDebug
```

## Pruebas

```bash
./gradlew testDebugUnitTest
```
